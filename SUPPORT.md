# Support Guide

Welcome to the **CommitPulse** support guide! Follow these steps for help.

## Troubleshooting Steps

1. **Check Existing Issues:** Search open/closed GitHub issues before posting.
2. **Verify Node.js Version:** Ensure you are running Node.js v18 or higher.
3. **Check Environment Variables:** Verify \.env.local\ contains a valid \GITHUB_TOKEN\.

## Getting Help

* **GitHub Issues:** For bugs or feature requests, open a new issue.
* **GSSoC Slack:** Reach out in the official channel for real-time chat.
